# UnitAI Website

Deploy on Vercel:

1. Create a GitHub repo named `unitai`.
2. Upload `index.html`.
3. In Vercel choose **Add New → Project**.
4. Import the GitHub repo.
5. Framework preset: **Other**.
6. Leave Build Command and Output Directory empty.
7. Click **Deploy**.

You will receive a URL similar to `unitai.vercel.app`.
